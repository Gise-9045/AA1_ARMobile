Este package facilita la integración de un sistema de alteración visual para objetos interactuables en un proyecto, ya que encapsula toda la lógica necesaria para gestionar listas de materiales, detectar interacciones mediante eventos de Unity y aplicar dinámicamente efectos visuales sobre los elementos seleccionados. Su principal utilidad en un entorno de simulación de Realidad Aumentada (AR) consiste en la capacidad de ver el entorno o los objetos bajo diferentes "filtros de cámara" (como se vería un objeto a través de una cámara térmica o con visión nocturna), lo cual enriquece el entrenamiento o el análisis de datos sin requerir hardware adicional. Su mayor aportación es permitir incorporar esta mecánica de forma rápida, modular y reutilizable, reduciendo el tiempo de implementación y evitando desarrollar la lógica de interfaz e interacción desde cero.

El package incluye una escena de prueba que contiene todos los scripts necesarios para gestionar la lógica del cambio de materiales de los objetos detectados. En esta misma escena ya se proporciona una interfaz lista para usar, que cuenta con un scroller con seis botones preconfigurados que cambian el material del objeto seleccionado aplicando filtros de cámara espaciales (como blanco y negro). Los esenciales del package están metidos dentro de un prefab con tal de facilitar arrastrar y meterlo dentro de otras escenas.

Desde el editor es posible escalar y personalizar este sistema de forma extremadamente sencilla. Para añadir más filtros, el flujo de trabajo es directo: solo debes crear tu propio material (por ejemplo, mediante Shader Graph), añadirlo a la lista expuesta en el script de cambio de materiales y, en el scroll de la interfaz, crear un botón nuevo. A este botón solo hay que asignarle la misma función que utilizan los demás en su evento OnClick, indicando en el número entero (int) que pide por referencia el índice exacto que ocupa tu nuevo material en la lista del script.

Es importante destacar que el paquete también incluye su propio URP-Performant que tiene la opción "opaque texture" activa, ya que si no, no se vería nada a través de los objetos a los que se les aplica los filtros.
